จัดการ Watchlist & ซิงก์กับ GitHub

คุณสามารถเพิ่ม/ลบ Ticker ได้บนหน้าเว็บนี้ทันที ข้อมูลจะถูกบันทึกไว้ในเบราว์เซอร์ของคุณ และคุณสามารถซิงก์กลับไปยัง GitHub Repository เพื่อให้ GitHub Actions คำนวณข้อมูลอัตโนมัติได้

ซิงก์อัตโนมัติไปยัง GitHub (ตัวเลือกเสริม)

ใส่ GitHub Personal Access Token (PAT) ที่มีสิทธิ์ repo เพื่อให้ระบบกดอัปเดตไฟล์ data/watchlist.json บน GitHub และสั่งรัน GitHub Actions ทันทีโดยไม่ต้องเปิด GitHub

หรือเปิดรัน Workflow ด้วยตัวเองที่ GitHub: เปิดหน้า GitHub Actions →
